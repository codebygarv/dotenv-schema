# Phase 1: Foundation & Core Validation (v0.1.0)

**Goal:** Establish the core validation logic and type-safe schema definition API.

* **Core API:** Build the `defineEnv()` function.
* **Type Validation:** Implement validators for String, Number, Boolean, URL, Email, Enum, and JSON.
* **Schema Constraints:** Add support for required variables, default values, min/max length, and custom validation functions.
* **TypeScript Support:** Implement automatic type inference from the schema.
* **Error Handling:** Create clear, actionable error messages for validation failures.
* **Security Basics:** Implement basic secret masking in error outputs.
* **Testing:** Establish unit testing for core validation logic.
